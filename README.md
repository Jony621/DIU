# Dev Days Dhaka 2026 — DIU Campus Journey

A procedural Three.js/Vite single-page cinematic campus experience.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Notes

- No external 3D models or texture images are used.
- Campus buildings, terrain, trees, particles and flags are generated procedurally.
- The optional ambient audio uses the supplied YouTube video ID and starts after user interaction.
- Internet access is required for the Google Fonts stylesheet, Three.js package installation, and YouTube iframe audio.
